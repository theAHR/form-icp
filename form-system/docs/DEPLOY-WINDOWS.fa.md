# راهنمای نصب سامانه روی کیس سرور (ویندوز) + چاپگر Magicard

این راهنما برای کسی نوشته شده که تجربهٔ نصب سرور ندارد. مراحل را **به ترتیب** و **بدون جا انداختن** انجام دهید.

## تصویر کلی

روی کیس سرور چهار چیز اجرا می‌شود:

| بخش | کار |
| --- | --- |
| PostgreSQL | دیتابیس؛ همهٔ اطلاعات اینجا ذخیره می‌شود. خودکار با روشن شدن ویندوز اجرا می‌شود. |
| برنامهٔ وب | همان سایتی که کاربران در مرورگر باز می‌کنند (پورت ۳۰۰۰). |
| سرویس صف چاپ (Worker) | کارت‌های صادرشده را از صف برمی‌دارد و به بخش چاپ می‌دهد. |
| رابط چاپ Magicard (Agent) | کارت را به درایور ویندوزی Magicard می‌فرستد. |

چاپگر Magicard با کابل USB به همین کیس وصل است. ۸ کاربر داخل اتاق با کابل شبکه (LAN) و مرورگر به کیس وصل می‌شوند؛ روی سیستم آن‌ها **هیچ نصبی لازم نیست**.

> در این راهنما فرض شده IP کیس سرور `192.168.1.10` است. همه‌جا آن را با IP واقعی کیس خودتان عوض کنید.

## مرحلهٔ ۱ — روی سیستم خودتان: آماده کردن بسته

### ۱-۱. گرفتن خروجی قالب فرم‌ها

قالب فرم‌ها و قالب کارت داخل دیتابیس سیستم شماست و باید جداگانه منتقل شود. در پوشهٔ پروژه، یک **Command Prompt** (cmd) باز کنید و بزنید:

```bat
npm run forms:export
```

فایلی به نام `forms-export.json` کنار پروژه ساخته می‌شود. اگر بعداً فرمی را ویرایش کردید، قبل از کپی دوباره این دستور را بزنید.

### ۱-۲. کپی پروژه روی فلش

فرض: فلش درایو `F:` است. در همان cmd:

```bat
robocopy . F:\form-system /E /XD node_modules .next storage .git test-results playwright-report .venv /XF .env
```

پوشه‌های سنگین و فایل `.env` (که رمزهای سیستم خودتان را دارد) کپی نمی‌شوند؛ روی سرور از نو ساخته می‌شوند.

## مرحلهٔ ۲ — آماده کردن کیس سرور

### ۲-۱. ویندوز

- ویندوز ۱۰ یا ۱۱ (۶۴ بیتی). به‌روزرسانی‌های ویندوز را نصب و یک بار ری‌استارت کنید.
- **خواب را خاموش کنید:** Settings ← System ← Power ← Screen and sleep ← «When plugged in, put my device to sleep after» = **Never**.
- **ساعت فعال (Active hours)** را در Windows Update روی ساعت کاری بگذارید تا وسط کار ری‌استارت نکند.

### ۲-۲. IP ثابت

اگر IP کیس عوض شود، کاربران دیگر به آن وصل نمی‌شوند. بهترین راه این است که از مسئول شبکه/مودم بخواهید برای این کیس IP رزرو کند. اگر خودتان انجام می‌دهید:

1. Settings ← Network & internet ← Ethernet ← روی کارت شبکه کلیک کنید.
2. جلوی **IP assignment** روی **Edit** بزنید، **Manual** و **IPv4** را روشن کنید.
3. IP (مثلاً `192.168.1.10`)، Subnet mask (`255.255.255.0`)، Gateway (معمولاً IP مودم، مثلاً `192.168.1.1`) و DNS (همان IP مودم) را وارد و ذخیره کنید.
4. در همان صفحه، **Network profile type** را روی **Private network** بگذارید.

IP را از بین IPهایی انتخاب کنید که سیستم دیگری از آن استفاده نمی‌کند.

### ۲-۳. نصب نرم‌افزارها (اینترنت لازم است)

به ترتیب نصب کنید:

1. **Node.js 24 LTS** — از nodejs.org نسخهٔ Windows Installer (.msi). در نصب، گزینه‌های پیش‌فرض را قبول کنید.
2. **PostgreSQL 17** — از postgresql.org/download/windows (نصب‌کنندهٔ EDB). در نصب:
   - یک رمز برای کاربر `postgres` می‌خواهد. **این رمز را یادداشت کنید.**
   - پورت را `5432` بگذارید.
   - در انتها Stack Builder را لازم ندارید؛ تیکش را بردارید.
3. **Python 3.12 یا جدیدتر** — از python.org. در اولین صفحهٔ نصب، تیک **Add python.exe to PATH** را بزنید.
4. **درایور Magicard** — از سایت رسمی Magicard (بخش Support/Drivers) درایور مدل چاپگر خود را بگیرید و نصب کنید. چاپگر را با USB وصل کنید.

بعد از نصب‌ها، یک بار ویندوز را ری‌استارت کنید.

### ۲-۴. تنظیم و تست چاپگر در ویندوز

1. Settings ← Bluetooth & devices ← Printers & scanners ← چاپگر Magicard.
2. **نام دقیق چاپگر** را همان‌طور که اینجا نوشته شده (با فاصله‌ها و حروف بزرگ و کوچک) یادداشت کنید؛ مثلاً `Magicard 300 NEO`.
3. در **Printing preferences**: اندازهٔ کارت **CR80**، جهت **Landscape**، **یک‌رو** و بدون تغییر اندازه (no scaling).
4. **Print test page** بزنید و مطمئن شوید از خود ویندوز درست چاپ می‌کند. تا وقتی این مرحله درست نشده، سراغ مراحل بعد چاپ نروید.

## مرحلهٔ ۳ — کپی پروژه روی سرور

1. پوشهٔ `C:\ICP` را بسازید و داخلش دو پوشهٔ `storage` و `backups` بسازید.
2. پوشهٔ `form-system` را از فلش به `C:\ICP\form-system` کپی کنید.

از اینجا به بعد، همهٔ دستورها را در **Command Prompt** و داخل پوشهٔ پروژه بزنید:

```bat
cd /d C:\ICP\form-system
```

## مرحلهٔ ۴ — ساخت فایل تنظیمات (`.env`)

```bat
node scripts\configure.mjs
```

این دستور فایل `.env` را با رمزهای تصادفی می‌سازد. حالا آن را باز کنید:

```bat
notepad .env
```

این خطوط را **تغییر** دهید (بقیه را دست نزنید):

```ini
APP_URL=http://192.168.1.10:3000
STORAGE_PATH=C:/ICP/storage
PRINT_SERVICE_URL=http://127.0.0.1:8090
```

و این دو خط را **به انتهای فایل اضافه** کنید (نام چاپگر دقیقاً همان مرحلهٔ ۲-۴):

```ini
PRINT_ALLOWED_PRINTERS=Magicard 300 NEO
PRINT_AGENT_DB=C:/ICP/print-agent.sqlite3
```

دو مقدار را از همین فایل یادداشت کنید:

- **رمز دیتابیس:** در خط `DATABASE_URL=postgresql://membership:XXXX@localhost...`، قسمت `XXXX` بین `membership:` و `@`.
- **رمز اولیهٔ مدیر:** مقدار `SEED_ADMIN_PASSWORD`.

ذخیره کنید و Notepad را ببندید.

> `STORAGE_PATH` حتماً باید مسیر کامل (مثل `C:/ICP/storage`) باشد؛ با مسیر نسبی، عکس‌ها با هر به‌روزرسانی پاک می‌شوند.
> فایل `.env` رمزهای سامانه است؛ آن را برای کسی نفرستید و از آن یک نسخه روی فلش امن نگه دارید.

---

## مرحلهٔ ۵ — ساخت دیتابیس

از منوی Start برنامهٔ **SQL Shell (psql)** را باز کنید. چهار سؤال اول (Server, Database, Port, Username) را با Enter رد کنید و رمز `postgres` (مرحلهٔ ۲-۳) را بزنید. سپس این دو خط را بزنید و `XXXX` را با رمز دیتابیس از مرحلهٔ ۴ عوض کنید:

```sql
CREATE USER membership WITH PASSWORD 'XXXX';
CREATE DATABASE membership OWNER membership;
```

بعد `\q` بزنید و پنجره را ببندید.

## مرحلهٔ ۶ — نصب و راه‌اندازی برنامه

در Command Prompt داخل `C:\ICP\form-system`، این دستورها را **یکی‌یکی** بزنید و صبر کنید هر کدام تمام شود:

```bat
npm ci
npm run build
npm run db:migrate
npm run db:seed
npm run forms:import
```

| دستور | کار |
| --- | --- |
| `npm ci` | دانلود کتابخانه‌ها (چند دقیقه، اینترنت لازم) |
| `npm run build` | ساخت نسخهٔ نهایی برنامه |
| `npm run db:migrate` | ساخت جدول‌های دیتابیس |
| `npm run db:seed` | ساخت کاربر `admin`، نقش‌ها و تنظیمات اولیه |
| `npm run forms:import` | وارد کردن قالب فرم‌ها و قالب کارت از `forms-export.json` |

> **`npm run db:seed` را فقط همین یک بار بزنید.** اجرای دوباره، فرم‌ها و قالب کارت را به حالت پیش‌فرض برمی‌گرداند.

## مرحلهٔ ۹ — اجرای سامانه

روی فایل `C:\ICP\form-system\scripts\windows\start-all.cmd` دوبار کلیک کنید. سه پنجره باز می‌شود:

- `ICP - App` — برنامهٔ وب
- `ICP - Print worker` — صف چاپ
- `ICP - Magicard agent` — رابط چاپگر (باید بنویسد `Print bridge ready`)

**این پنجره‌ها را نبندید** (می‌توانید Minimize کنید). بستن هر کدام یعنی آن بخش از کار می‌افتد.

### اولین ورود

1. روی خود کیس، مرورگر را باز کنید و بروید به `http://localhost:3000`.
2. نام کاربری `admin` و رمز `SEED_ADMIN_PASSWORD` (مرحلهٔ ۴) را بزنید. سامانه از شما می‌خواهد رمز جدید بگذارید.
3. حالا `.env` را باز کنید و مقدار جلوی `SEED_ADMIN_PASSWORD=` را پاک کنید (خود خط بماند، مقدارش خالی شود).
4. از یکی از سیستم‌های اتاق، مرورگر را باز کنید و بروید به `http://192.168.1.10:3000`. باید صفحهٔ ورود بیاید.
5. از منوی «کاربران» برای هر یک از ۸ نفر حساب جدا بسازید. از حساب `admin` برای کار روزانه استفاده نکنید.

## مرحلهٔ ۱۰ — وصل کردن Magicard در سامانه

1. وارد سامانه شوید ← **تنظیمات** ← بخش **چاپگرها** ← روی **تنظیمات** کنار `Magicard 300 NEO` بزنید.
2. **نام دقیق درایور Windows** را دقیقاً برابر نام چاپگر در ویندوز (مرحلهٔ ۲-۴) بگذارید.
3. **فعال‌سازی پردازش صف** را روی **فعال** بگذارید و ذخیره کنید.
4. برای یک عضو آزمایشی کارت صادر کنید و در صفحهٔ **صف چاپ** وضعیت را ببینید. چاپگر باید کارت را چاپ کند.

### تأیید چاپ (مهم)

ویندوز فقط می‌گوید کار را به چاپگر داده، نه این‌که کارت واقعاً سالم بیرون آمد. برای جلوگیری از چاپ تکراری، بعد از هر چاپ، سامانه منتظر تأیید شماست و در صف چاپ «در انتظار تأیید فیزیکی چاپ» می‌نویسد.

روی کیس، فایل `scripts\windows\print-jobs.cmd` را اجرا کنید:

- فهرست آخرین کارهای چاپ نشان داده می‌شود.
- اگر کارت درست چاپ شد: **۱** را بزنید و شناسهٔ کار (مقدار `id` در فهرست) را وارد کنید.
- اگر کارتی بیرون نیامد: **۲** را بزنید و شناسه را وارد کنید؛ سپس در صفحهٔ صف چاپ سامانه، «تلاش مجدد» بزنید.

چند ثانیه بعد، وضعیت در سامانه به «چاپ‌شده» تغییر می‌کند.

> این رابط چاپ هنوز روی دستگاه واقعی Magicard آزمایش نشده است. اولین کارت‌ها را با کارت خام آزمایشی چاپ کنید و حاشیه‌ها، عکس و خوانایی QR را بررسی کنید.

## مرحلهٔ ۱۱ — اجرای خودکار با روشن شدن کیس

در cmd داخل پوشهٔ پروژه یک بار اجرا کنید:

```bat
scripts\windows\install-autostart.cmd
```

این کار یک وظیفه در **Task Scheduler** با نام `ICP-Membership-AutoStart` می‌سازد: **یک دقیقه بعد از ورود به ویندوز**، منتظر آماده شدن PostgreSQL می‌ماند و سامانه را بالا می‌آورد. لاگ در `C:\ICP\logs\icp-startup.log` و `icp-app.log` است.

PostgreSQL با روشن شدن کیس (سرویس Automatic) اجرا می‌شود؛ **برنامهٔ عضویت بعد از ورود کاربر به ویندوز** بالا می‌آید. اگر کیس بدون ورود روی صفحهٔ قفل بماند، سامانه بالا نمی‌آید مگر Auto-Logon تنظیم شود.

برای اجرای دستی (با پنجرهٔ قابل‌دیدن): `scripts\windows\start-all.cmd`

## مرحلهٔ ۱۲ — پشتیبان‌گیری روزانه (خیلی مهم)

اسکریپت `scripts\windows\backup.cmd` از دیتابیس و عکس‌ها در `C:\ICP\backups\<تاریخ>` نسخهٔ پشتیبان می‌سازد و نسخه‌های قدیمی‌تر از ۳۰ روز را پاک می‌کند. یک بار دستی اجرایش کنید و مطمئن شوید پیام `Backup saved` می‌آید.

برای اجرای خودکار هر روز:

1. Start ← **Task Scheduler** ← **Create Basic Task**.
2. نام: `ICP Backup` ← Trigger: **Daily**، ساعت پایان کار (مثلاً ۱۴:۰۰).
3. Action: **Start a program** ← Program: `C:\ICP\form-system\scripts\windows\backup.cmd`.
4. Finish.

هفته‌ای یک بار پوشهٔ `C:\ICP\backups` را روی یک هارد یا فلش جدا هم کپی کنید؛ اگر هارد کیس خراب شود، پشتیبانِ روی همان هارد هم از بین می‌رود.

### برگرداندن پشتیبان (فقط در صورت خرابی)

پنجره‌های سامانه را ببندید، سپس در cmd (به‌جای `XXXX` رمز دیتابیس و به‌جای تاریخ، پوشهٔ پشتیبان موردنظر):

```bat
"C:\Program Files\PostgreSQL\17\bin\pg_restore.exe" --clean --if-exists --no-owner --dbname="postgresql://membership:XXXX@localhost:5432/membership" C:\ICP\backups\2026-10-05_1400\database.dump
robocopy C:\ICP\backups\2026-10-05_1400\storage C:\ICP\storage /E
```

## به‌روزرسانی برنامه در آینده

1. قبلش `backup.cmd` را اجرا کنید.
2. پنجره‌های سامانه را ببندید.
3. فایل‌های جدید پروژه را روی `C:\ICP\form-system` کپی کنید (به `.env` و `.venv` دست نزنید).
4. در cmd داخل پوشهٔ پروژه:

   ```bat
   npm ci
   npm run build
   npm run db:migrate
   ```

5. `start-all.cmd` را دوباره اجرا کنید.

**`npm run db:seed` را در به‌روزرسانی نزنید.**

## مشکلات رایج

| مشکل | راه‌حل |
| --- | --- |
| روی خود کیس باز می‌شود ولی از سیستم‌های دیگر نه | IP را با `ipconfig` روی کیس چک کنید؛ قانون فایروال (مرحلهٔ ۸) را بررسی کنید؛ پروفایل شبکه باید Private باشد. |
| صفحه اصلاً باز نمی‌شود | پنجرهٔ `ICP - App` باز است؟ اگر خطا نوشته، متنش را عکس بگیرید. |
| خطای اتصال به دیتابیس | سرویس PostgreSQL را در `services.msc` (نام `postgresql-x64-17`) چک کنید که Running باشد؛ رمز در `.env` با رمز مرحلهٔ ۵ یکی باشد. |
| کارت در صف چاپ می‌ماند | چاپگر در تنظیمات سامانه «فعال» است؟ پنجره‌های Worker و Agent باز هستند؟ نام چاپگر در سامانه، در `PRINT_ALLOWED_PRINTERS` و در ویندوز دقیقاً یکی است؟ |
| Agent می‌گوید `Configure driver to CR80 landscape` | تنظیمات Printing preferences چاپگر (مرحلهٔ ۲-۴) را روی CR80 و Landscape بگذارید. |
| در صف چاپ «نتیجه چاپ نامشخص» | چاپگر را نگاه کنید؛ با `print-jobs.cmd` یا تأیید (۱) یا ناموفق (۲) را ثبت کنید. |
| QR کارت روی گوشی باز نمی‌شود | `APP_URL` در `.env` باید IP کیس باشد و گوشی باید به همان شبکه وصل باشد. |
